# LOCUS — цифровая картография Казахстана

**LOCUS** — авторский картографический проект о рельефе Казахстана. В центре проекта — пластика земной поверхности, формы местности и высотные различия; административные границы, населённые пункты, дороги и гидрография служат пространственным контекстом.

**Сайт проекта:** https://ktesifon-star.github.io/locus/

## Каталог

В каталоге публикуются авторские карты рельефа областей и районов Казахстана. Для каждой карты указываются год создания, картографическая проекция и источник цифровой модели рельефа (DEM).
